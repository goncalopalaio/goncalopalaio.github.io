Spare Time Projects

  • fibre-wallpaper - Android Live Wallpaper
  • timelapse - Command line utility to record timelapse video using a webcam
  • gonet-nural - Small experiment in training a simple Tensorflow model using Python, exporting it and reimplementing it in C with minimal dependencies.
  • adb-control-center - Proof-of-concept (barely works) interface for common android ADB commands used during development. Connects to ADB server through sockets.
  • lorenz-s-attractor-sketch-c - Small program that renders a Lorenz’s attractor
