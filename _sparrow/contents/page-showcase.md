This is a random assortment of projects I've worked on in the past.

## Spare Time Projects

- [lcat](https://github.com/goncalopalaio/lcat) - Colors, filters and annotates adb logcat output.
- [fibre-wallpaper](https://github.com/goncalopalaio/fibre-wallpaper) - Android Live Wallpaper
- [timelapse](https://github.com/goncalopalaio/timelapse) - Command line utility to record timelapse video using a webcam
- [gonet-nural](https://github.com/goncalopalaio/gonet-nural) - Small experiment in training a simple Tensorflow model using Python, exporting it and reimplementing it in C with minimal dependencies.
- [adb-control-center](https://github.com/goncalopalaio/adb-control-center) - Proof-of-concept (barely works) interface for common android ADB commands used during development. Connects to ADB server through sockets.
- [lorenz-s-attractor-sketch-c](https://github.com/goncalopalaio/lorenz-s-attractor-sketch-c) - Small program that renders a Lorenz's attractor
- [RRRobot](https://github.com/goncalopalaio/RRRobot) - Experiments with dynamic loading of .dex files during the runtime of an Android application. Runs UiAutomator code contained in the .dex file
