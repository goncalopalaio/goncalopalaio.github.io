Prefixes on md files in _contents:

page-

-> Creates a new sub page that will be shown at the top in all of the website pages.

post-

-> Creates and publishes a blog post from the file.

unlisted-post-

-> Creates and publishes a blog post from the file. The main difference from **post-** is that the blog post will not be listed in the list of posts.


All other prefixes will be ignores and no page will be generated for them.
